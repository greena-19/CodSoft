# 🚀 CodSoft Projects

This repository contains Java-based projects developed during the CodSoft Internship. Each project focuses on core programming concepts such as logic building, user interaction, and object-oriented programming.

---

## 📂 Projects

### 🔹 Task 1 – Number Guessing Game

**Description:**  
A console-based game where the system generates a random number between 1 and 100, and the user has to guess it within a limited number of attempts. The game provides hints (too high / too low) and keeps track of the score across multiple rounds.

**Features:**  
- Random number generation using Java  
- Limited attempts (5 turns per round)  
- Hint system (high / low feedback)  
- Score tracking across rounds  
- Option to play multiple rounds  
- Final score display at the end  

**Tech Stack:**  
- Java  
- Scanner  
- Random  

---

### 🔹 Task 2 – Student Grade Calculator

**Description:**  
A simple program that calculates the total marks, average percentage, and assigns a grade based on marks entered for three subjects.

**Features:**  
- Input marks for multiple subjects  
- Total marks calculation  
- Average percentage calculation  
- Grade assignment based on percentage  
- Clear output display  

**Grading Criteria:**  
- A: ≥ 90  
- B: ≥ 80  
- C: ≥ 70  
- D: ≥ 60  
- E: ≥ 50  
- F: < 50  

**Tech Stack:**  
- Java  
- Scanner  

---

### 🔹 Task 3 – ATM Interface System

**Description:**  
A console-based ATM simulation that allows users to perform banking operations like deposit, withdrawal, and balance checking using object-oriented programming principles.

**Features:**  
- Deposit money  
- Withdraw money with validation  
- Check account balance  
- Menu-driven interface  
- Continuous loop until exit  

**Concepts Used:**  
- OOP (Object-Oriented Programming)  
- Classes & Objects  
- Encapsulation  

**Tech Stack:**  
- Java  
- Scanner
